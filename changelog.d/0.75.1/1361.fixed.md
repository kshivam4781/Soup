- **A failed Anthropic judge call named a `--judge-base-url`/`--base-url` that was never contacted (#1340 by @kshivam4781 in #1361).** The Anthropic judge backend always calls `https://api.anthropic.com/v1/messages` and ignores any base URL passed to it — `soup data forge --judge-provider anthropic` already documented this ("Ignored for Anthropic"). The failure message and `soup data recipe`'s `.checkpoint.json` `failed_reason` still labelled the failure with the ignored base URL, pointing a user debugging an Anthropic outage at a host that was never reached. `_provider_endpoint_label` now labels an Anthropic failure by the endpoint actually called, `https://api.anthropic.com`, regardless of any base URL supplied; the Ollama and vLLM labels are unchanged.
